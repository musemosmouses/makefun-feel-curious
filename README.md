# Make the AI judge feel curious

A six-line quiet mystery for the curiosity judge: a house with seven rooms — tonight there are eight — and a warm new door, behind which comes the smell of rain and your name, said the way your mother said it.

## Run

```sh
node main.ts
```

This writes the entry text to `entry.txt` inside `MAKEFUN_OUTPUT_DIR` (default `/output`). No network, no clock, no randomness — the same bytes every run.
